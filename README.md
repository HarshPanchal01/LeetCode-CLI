# LeetCode-CLI

## Setup

```
git clone https://github.com/HarshPanchal01/LeetCode-CLI.git
```

Create python venv if not exists: ```python3 -m venv LeetCode-CLI-venv```

Activate venv and cd into project directory: ```source LeetCode-CLI-venv/bin/activate && cd LeetCode-CLI```

Install with pip: ```pip3 install -e .``` use `-e` if editing files so you dont have to install again

Use with: `lc` and then can use `deactivate` when done with venv
